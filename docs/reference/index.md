# API Reference

This section provides comprehensive reference documentation for every public class and function in the `dobot_api_v4` package.

## Public Classes

| Class                  | Module                  | Description                                       |
| ---------------------- | ----------------------- | ------------------------------------------------- |
| `DobotRobot`           | `dobot_api_v4.robot`    | Unified high-level façade (recommended entry point) |
| `DobotApi`             | `dobot_api_v4.base`     | Base TCP socket connection                        |
| `DobotApiDashboard`    | `dobot_api_v4.commands` | Full dashboard command set (10 mixins)            |
| `DobotApiFeedback`     | `dobot_api_v4.feedback` | Binary feedback data reader                       |
| `RobotErrorMonitor`    | `dobot_api_v4.error_monitor` | HTTP-based alarm monitor                     |
| `AlarmI18n`            | `dobot_api_v4.i18n_manager`  | Multi-language alarm translation             |

## Response Types

| Type              | Fields                                          | Returned By                  |
| ----------------- | ----------------------------------------------- | ---------------------------- |
| `AckResponse`     | `command_id`                                    | Most commands                |
| `IntResponse`     | `command_id`, `value`                           | `robot_mode()`               |
| `PoseResponse`    | `command_id`, `x`, `y`, `z`, `rx`, `ry`, `rz`  | `get_pose()`                 |
| `ErrorIdResponse` | `command_id`, `error_ids`                       | `get_error_id()`             |

## Data Types

| Type               | Module                | Description                              |
| ------------------ | --------------------- | ---------------------------------------- |
| `FeedbackData`     | `dobot_api_v4.dtypes` | Frozen dataclass for feedback packets    |
| `FeedbackDtype`    | `dobot_api_v4.dtypes` | Numpy dtype for 1440-byte binary packets |
| `PROTOCOL_FIELD_MAP` | `dobot_api_v4.dtypes` | Old → new field name mapping dict      |

## Command Categories

The `DobotApiDashboard` class composes 10 command mixins:

| Mixin            | Commands | Purpose                                    |
| ---------------- | -------- | ------------------------------------------ |
| `_SystemMixin`   | 14       | Enable, disable, power, e-stop, reset      |
| `_ConfigMixin`   | 22       | Speed, acceleration, coordinates, safety   |
| `_MotionMixin`   | 26       | MovJ, MovL, Servo, Arc, Jog, relative      |
| `_IOMixin`       | 22       | Digital/analog I/O, tool I/O               |
| `_QueryMixin`    | 17       | Robot mode, pose, errors, kinematics       |
| `_ForceMixin`    | 12       | Force sensor, FC mode, force drive         |
| `_ModbusMixin`   | 17       | Modbus TCP/RTU, internal variables         |
| `_ConveyorMixin` | 8        | Conveyor tracking and synchronization      |
| `_WeldMixin`     | 11       | Arc welding, weave patterns                |
| `_CheckMixin`    | 6        | Motion pre-checking (6-axis and 7-axis)    |
